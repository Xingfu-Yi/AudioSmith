# Security policy

## Supported versions

Until the first stable release, security fixes are provided only on the latest `main` branch and the newest GitHub prerelease.

## Reporting

Please do not disclose vulnerabilities involving microphone capture, Accessibility permissions, synthesized input, model download integrity, path traversal, or Skill loading in a public issue before a fix is available.

Until a dedicated security address is configured, open a private GitHub security advisory in the repository. Do not include real recordings, transcripts, signing credentials, or personal data in reports.

Audio Smith Skills are intentionally data-only. A report showing that a Skill can cause executable code to run is considered high severity.
