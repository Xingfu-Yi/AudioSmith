# Support

Before opening an issue:

1. Check the system requirements and current limitations in [README.md](README.md).
2. Check [docs/SKILLS.md](docs/SKILLS.md) for Skill installation and validation problems.
3. Search existing GitHub issues after the remote repository is published.

Use the bug-report form for reproducible problems and include the app version, chip, physical memory and macOS version. Never upload private recordings, transcripts, model files, signing credentials or personal data.

Security-sensitive reports must follow [SECURITY.md](SECURITY.md).
